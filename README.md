# NDRMS | AI 기반 재난 피해 심사 및 지원금 산정 지원 플랫폼

KT AIVLE School 팀 프로젝트로 진행한 AI 기반 재난 피해 심사 지원 서비스입니다.

본 저장소는 프로젝트의 전체 소스코드를 복제한 저장소가 아닌, **개인 담당 업무와 문제 해결 경험을 정리한 프로젝트 소개 자료**입니다.

## 1. 프로젝트 개요

자연재난 피해 신고부터 AI 기반 피해등급 분석, 담당자 심사, 지원금 산정 및 보고서 생성까지 이어지는 행정 업무를 지원하는 플랫폼입니다.

AI가 피해등급 후보와 판단 근거를 제공하고, 최종 결정은 담당자가 검토하도록 설계하여 행정 업무의 효율성과 판단 과정의 투명성을 높이는 것을 목표로 했습니다.

## 2. 주요 기능

- 피해 신고 정보 조회 및 관리
- 피해 이미지 기반 AI 분석 결과 제공
- 담당자 피해등급 심사 및 승인
- 피해등급에 따른 지원금 산정
- 심사 결과 및 보고서 생성

## 6. 문제 해결 경험

### API 요청 경로 불일치 문제

**문제 상황**

프론트엔드에서 API를 호출했으나 일부 요청이 정상적으로 처리되지 않는 문제가 발생했습니다.

**확인 과정**

- Chrome 개발자 도구의 Network 탭에서 요청 URL과 응답 상태 확인
- Swagger에 정의된 API 경로와 실제 프론트엔드 요청 경로 비교
- 프론트엔드와 백엔드의 경로 불일치 확인

**대응**

- 프론트엔드에서 발생한 오류는 직접 수정
- 백엔드 수정이 필요한 부분은 확인한 내용을 담당 팀원에게 전달
- 팀원과 API 연동 사항을 공유하며 수정 과정에 협력

**배운 점**

문제의 발생 지점을 구분하고 재현에 필요한 정보를 정확하게 전달하는 것이 효율적인 오류 해결과 협업에 중요하다는 점을 배웠습니다.

## 7. 프로젝트를 통해 배운 점

기능 구현뿐 아니라 사용자 업무 흐름과 데이터 전달 과정을 함께 고려하는 경험을 쌓았습니다.

특히 API 연동 문제를 확인하는 과정에서 요청 조건과 응답 결과를 분석하고, 관련 정보를 팀원에게 전달하는 역량을 키웠습니다.

이 경험을 바탕으로 서비스가 요구사항에 맞게 동작하는지 확인하고 품질을 개선하는 QA 업무에 관심을 갖게 되었습니다.
